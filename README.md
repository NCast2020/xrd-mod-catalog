# Xrd Mod Catalog

Mods for **Guilty Gear Xrd -REVELATOR- (REV 2)**, browsed and downloaded from inside [Xrd Mod Manager](https://github.com/NCast2020/xrd-mod-manager-releases).

**Download mods:** open Xrd Mod Manager → **Browse catalog**. No account needed.

**Share your mod:** select it in Xrd Mod Manager → **Share**, sign in with GitHub. The archive is published as a release in your own `xrd-mods` repository and the app opens a pull request here adding `mods/<id>.json`. Once the pull request is merged, the mod shows up for everyone.

How it works: each mod is one file in `mods/`. On every merge a workflow validates them and rebuilds `catalog.json`, the single file the app downloads.

---

**Скачать моды:** открой Xrd Mod Manager → **Каталог модов**. Аккаунт не нужен.

**Поделиться модом:** выбери его в Xrd Mod Manager → **Поделиться**, войди через GitHub. Архив выложится в твой репозиторий `xrd-mods`, а сюда придёт заявка. Когда её примут, мод увидят все.
